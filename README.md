# Blockchain Voting DApp

A simple decentralized voting application built using **Solidity** and **Ethereum Sepolia testnet**.

## Tools Used
- Solidity  
- Remix IDE  
- MetaMask  
- Ethereum Sepolia Testnet  
- HTML, CSS, JavaScript  

## Features
- One wallet address can vote only once  
- Votes are stored securely on blockchain  
- Transparent and tamper-proof voting  

## How to Run
1. Deploy the smart contract using Remix and MetaMask  
2. Open `index.html` using Live Server  
3. Connect MetaMask wallet (Sepolia network)  
4. Vote and view results
